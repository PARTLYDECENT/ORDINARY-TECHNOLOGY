About This Generator

This generator creates unique planets with smooth terrain and multiple biomes using Perlin noise and sine waves. The planets have:

  • Smooth, continuous terrain without voxelization or rough edges
  • Multiple biomes: oceans, beaches, forests, grasslands, mountains, deserts, tundra, and ice caps
  • Realistic elevation changes based on latitude and noise patterns
  • Wave-like features for more natural terrain formations
  • Customizable parameters for endless variety

The generated PLY files can be imported into 3D software like Blender, MeshLab, or game engines.
